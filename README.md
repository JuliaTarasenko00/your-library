# 📔 Read Journey

Read Journey is a web application that helps users track their reading progress. Users can sign up, add books from the database or their own custom books, and view visual reports on their reading progress.
---

✨ **Read Journey** - Read, Track, Improve!

## 📌 Features
- 📖 User registration and authentication
- 📊 Track reading progress
- 📚 Add custom books if they are not in the database
- 📈 Visual representation of reading statistics
- 🔍 Search for books in the database
- 🎨 Modern and user-friendly UI using Tailwind CSS

---

## 🚀 Technologies & Dependencies
The project is built with **React** using **Vite** and the following libraries:

- [React](https://react.dev/) `^18.3.1`
- [React Hook Form](https://react-hook-form.com/) `^7.54.2` (form management)
- [Yup](https://github.com/jquense/yup) `^1.6.1` (data validation)
- [@tanstack/react-query](https://tanstack.com/query) `^5.64.1` (data fetching and state management)
- [Axios](https://axios-http.com/) `^1.7.9` (HTTP requests)
- [React Router](https://reactrouter.com/) `^7.1.1` (routing)
- [Chart.js](https://www.chartjs.org/) `^4.4.7` + [react-chartjs-2](https://react-chartjs-2.js.org/) `^5.3.0` (data visualization)
- [Date-fns](https://date-fns.org/) `^4.1.0` (date management)
- [Sonner](https://sonner.emilkowal.ski/) `^1.7.2` (notifications)
- [Tailwind CSS](https://tailwindcss.com/) `^3.4.17` (styling)
- [vite-plugin-svgr](https://github.com/pd4d10/vite-plugin-svgr) `^4.3.0` (SVG support)
